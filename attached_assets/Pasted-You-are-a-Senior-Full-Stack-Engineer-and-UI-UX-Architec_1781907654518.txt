# Database Schema

### profiles

| Column    | Type                         |
| --------- | ---------------------------- |
| id        | UUID (matches auth.users.id) |
| name      | text                         |
| type      | text ('dj' or 'venue')       |
| phone     | text                         |
| instagram | text                         |

### availability

| Column    | Type                           |
| --------- | ------------------------------ |
| id        | integer                        |
| vendor_id | UUID                           |
| date      | date                           |
| status    | text ('available' or 'booked') |

## 2. Public Search Area (No Login Required)

### Search Mode Toggle

Provide two search modes:

#### Search by Date

User selects a date.

Application must:

1. Query availability table
2. Find vendors marked "available" on selected date
3. Join with profiles table
4. Display results

Result cards must include:

* Vendor Name
* Type Badge
* Phone Number
* WhatsApp Button
* Instagram Button
* Availability Status
* Contact CTA

WhatsApp link format:

```javascript
https://wa.me/PHONE_NUMBER
```

Instagram link format:

```javascript
https://instagram.com/USERNAME
```

---

#### Search by Vendor

User selects a vendor from dropdown.

Application must:

1. Fetch selected vendor's available dates
2. Find all other vendors available on those same dates
3. Group results by date
4. Display matching DJs and Venues

Show:

* Date
* Vendor Name
* Vendor Type
* Contact Information
